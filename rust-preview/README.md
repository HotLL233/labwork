# Rust + SQLite 表格验证版 0.0.2-alpha.1-grid.6

默认端口为18809。安装时可设置端口、数据目录、服务器私网IPv4和12–256字符共享访问口令；IP留空只供本机访问。局域网客户端通过 `http://服务器IP:端口` 访问，无需安装独立应用。grid.5及更旧版本保留，程序按版本隔离。

## 工作簿、项目和月份

在页面导入 XLSX 后，自动显示项目及工作表目录。D006和Q已接入14个服务端计算方法；其他项目先按原表浏览，不自动推断计算规则。原始上传文件使用副本，安装包不携带业务文件。

页面布局压缩了录入区和原表预览之间的空白。选择项目、工作表或已接入方法后录入。每行保存一次测定，最多200行批量计算；支持多格粘贴、选区复制、向下填充、数值/日期/批号末尾递增和撤销。手机提供字段卡片及填充按钮。日期和批号只在首行填写，后续留空，不新增合并。

点击“全部批号计算并预览”核对候选 XLSX，再确认写入。确认前工作文件不变；写入时保留备份，文件发生变化会拒绝覆盖。D006/Q方法中的日期按Excel日期格式显示。

工作文件位于 `data/months/YYYY-MM/workbooks`。历史月只读。用户点击“新建月份”并确认后，以上月文件创建空白模板，保留格式、公式与参数，清除日期、批号、录入值和结果。未知工作表须先确认清空范围，程序不会猜测哪些单元格可以删除。

首次使用会把旧 `data/workbooks` 复制到首个月份，保留旧目录原件。之后只向月份目录写入新记录，不再同步旧目录。请使用页面导入入口，避免把新文件放入已不接收写入的旧目录。

## 安装和启动

中文安装器默认安装到 `%LOCALAPPDATA%\Programs\理化检测平台`；程序保存在 `versions/版本号`，开始菜单统一指向当前版本，默认数据位于安装根目录 `data`。已有稳定产品安装沿用原位置和设置。双击程序直接托盘启动；双击托盘打开页面，右键正常停止。Windows可能将图标放在任务栏“^”隐藏区。

从旧grid.3/grid.4首次升级时，默认中文产品目录位于旧安装目录同级，带平台标记的旧data会预填。先停止旧实例；旧版自定义数据目录需手动选择原路径。安装不会复制迁移或删除此来源目录；grid.6启动时的首次月份复制另见上文。正在使用的数据目录会拒绝安装，同一个数据目录不能同时运行多个实例。

配置文件位于程序旁 `labwork.json`，包含 `port`、`data_dir`、`lan_ip`、`access_password`。共享口令仅保存在本地配置，勿共享配置文件。局域网重装需重新输入口令，其他安装选项沿用上次值。静默安装支持 `/PORT=18809 /DATADIR="D:\LabworkData" /LANIP=192.168.1.50 /ACCESSPASSFILE="D:\临时口令.txt"`；口令从UTF8文件读取，安装后删除临时文件，不应把口令放命令行。

安装器不自动提权或更改防火墙。管理员按服务器实际IP与端口添加规则，例如现场IP172.28.10.177、端口1234：

```powershell
New-NetFirewallRule -DisplayName 'LabworkRust-grid6-LAN' -Direction Inbound -Action Allow -Protocol TCP -LocalAddress 172.28.10.177 -LocalPort 1234 -RemoteAddress LocalSubnet -Profile Any
```

该规则限指定本机私网IP及同网段来源，无需修改当前网络类型。客户端使用 `http://172.28.10.177:1234`，按实际配置替换地址。

便携包包含EXE、说明和空data目录。解压后双击程序，默认本机模式，配置中的相对data路径按EXE目录解析。安装包和便携包均不包含工作簿、账号或数据库。

## 升级与回退

升级前停止平台并备份整个data目录。卸载保留数据，版本程序文件在升级时保留。

回退grid.5时先退出当前实例，再运行保留的grid.5程序，并使用升级前备份的独立数据目录。旧root/workbooks保留的是升级前文件；grid.6产生的新月份和新增记录不会自动同步回grid.5。保留新旧数据，核对新增记录后再切换，不能把启动旧EXE当作无损数据回退。

## 构建与验证

需要Rust stable及Windows MSVC构建工具；用户运行无需Rust、Python或独立数据库。Windows CRT静态链接。

```powershell
cargo test --locked
cargo build --release --locked
node tools/grid-test.cjs
```

文件回归核对14个方法、十进制输出、预览不写、备份/冲突与幂等；安装回归核对配置、真实HTTP启动、数据保留和无效参数拒绝。以发布目录的验收结果为准。

本版使用HTTP和共享口令，限可信实验室内网；完整分账号权限、HTTPS及正式服务迁移仍未完成。未将Office全部编辑功能搬入网页；未知项目仅浏览，清空范围需确认。实际手机、浏览器视觉与Excel/WPS原生重算尚未验收。
