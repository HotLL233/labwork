# labwork-v0.0.7

labwork 在实验室内网浏览器中录入、计算、预览并把结果写入服务器本机关联的 XLSX。Rust + SQLite 单服务器运行，无需独立客户端或外部数据库。中文安装器支持端口、数据目录、服务器私网 IPv4、访问口令和内网端口规则；默认端口18810，已有安装继续沿用配置。

项目名称统一为 `labwork`，命名约定见源码 [命名规范](../docs/命名规范.md)，发布目录也附该文件。版本号使用三段数字，本版中文安装包为 `labwork-v0.0.7.exe`，不加 alpha、grid 等后缀。程序为 `labwork.exe`，发布目录及安装版本目录均使用 `labwork-v版本号`。便携包为 `labwork-v版本号-Windows-x64.zip`，源码包为 `labwork-v版本号-Source.zip`。历史发布保留原名以便回退。

本版精简工作表上方的重复标题和说明，缩小操作区间距，让表格更早显示。原表和计算/写入预览继续按行号显示全部行，包括中间历史记录和空白行；只读浏览与月份模板分页、每次最多200行测定、升级口令沿用和一次性内网端口配置继续保留。原文件关联、空白模板预览、导入项目删除入口及已损坏 Excel 拒写检查沿用。已有损坏文件须先另存并用写入前备份核对，程序不会自动重建过去丢失的格式。升级后重新生成预览。

## 关联原文件后录入

原文件位于运行 labwork 的服务器本机。浏览器上传只能复制文件，无法取得原文件完整路径；上传副本不等于完成关联。未关联时禁止确认写入和保存格式。

已有项目直接选中当前项目和月份，点击“关联原文件”进入工作簿管理，在“关联当前项目原文件”中自行填写“服务器原文件路径”，点击“关联此项目原文件”。当前已有 EF1 时，选择 EF1 即可，无需再导入一个 EF 项目。关联操作不修改文件；下一次预览以原文件实际内容、公式和既有记录为准。关联成功后重新计算或预览，再“确认写入原文件”。

新项目使用“关联服务器工作簿 · 新项目”，填写项目编号、名称和服务器路径，点击“关联并生成目录”，一次完成目录导入和原文件关联。重复项目或已关联其他项目的原文件会被拒绝，失败不会留下未关联项目。路径由使用者在页面配置，不在代码中预设业务文件路径。“上传工作簿副本（可选）”仅作为复制入口，之后仍须关联原文件。

在当前月份的工作簿管理中，“解除关联”保留项目和上传副本，停止向源文件写入，可重新关联。“删除导入项目”从当前项目目录移除误导入或重复项目，归档平台工作副本并保留源文件、旧月份和写入历史。两种操作均须页面确认；历史月份不能修改，尚未完成的写入须先处理。

计算结果和手动录入结果均追加到关联原文件，月份工作副本同步保存。页面显示原文件路径，确认成功后可下载已保存工作簿。每次写入保留备份；Excel/WPS 或其他用户在预览后修改原文件，会拒绝覆盖并要求重新预览。文件被占用导致同步中断时，通过写入历史重试原写入，不重复追加。

升级前已仅保存到月份副本、尚未出现在原文件中的记录不会自动合并。关联后原文件是依据；请先下载保留旧副本并核对需补录数据，再在关联后的页面补录，避免用旧副本整本覆盖原文件。旧版尚未写入的预览须在新版本重新生成。

## 项目、方法和月份

工作簿导入后按真实工作表生成项目目录。原表识别回归覆盖12本工作簿、138个工作表，其中124个可计算或手动登记，11张目录表只供导航，3张缺少日期列表只读；识别可用不等于完成实验室业务核定。

每行一次测定，每次最多200行；支持多格粘贴、选区复制、向下填充、数字/日期/批号末尾递增和撤销。日期和同批号仅首行填写，后续留空，不新增合并。手机使用单列字段卡片与底部预览/写入操作。所有公式计算在服务器完成，预览不修改原文件。

录入界面的原表和计算/写入预览从第一行至末行连续显示，保留中间历史记录和空白行，可滚动查看。只读工作表浏览和月份模板预览仍按每页最多200行分页。

历史月份只读。点击“新建月份并预览”即可查看新月份，无需逐表确认清空规则。平台自动识别日期、批号、测定输入和结果区域；有效的旧规则继续使用，结构变更时重新识别，未知表与目录表默认保留。预览可切换项目和工作表，对照上月原值，实际将清空的单元格高亮显示；需要微调时在表格中选择区域，点击“清空选区”或“保留原值”；可用“撤销调整”恢复本次调整。公式、已识别固定参数、前两行与目录表受保护，不因选区清空而删除。

含暂不支持公式或无法识别数据区的表默认保留原值，可在预览中显式选区清空。

预览不创建月份或写入原文件，确认后才生成新月。原文件、目录、规则或选区调整在预览后变化会拒绝生成，须重新预览。已有原文件关联时，新月按项目/年份/月目录结构生成新的空白原文件并关联，跨年使用新的年份目录；已按此结构保存的路径继续沿用。直接放在普通文件夹中的源文件，也会生成安全的项目/年/月目标。目标文件冲突时仍可查看模板及问题，但不能确认覆盖。示例：

```text
EF-理化/
├─ 2026/2026.12/EF-理化-202612.xlsx
└─ 2027/2027.01/EF-理化-202701.xlsx
```

平台镜像目录为 `data/months/YYYY-MM/workbooks`。旧 `data/workbooks` 在首次月份初始化时复制保留，后续不会写入该旧目录。已保存的有效 `month-rules-v2.json` 规则兼容，默认操作无需编辑该文件或逐表保存规则。旧文件留存供回退。

## 单元格格式

支持选区行高、列宽、数字小数位、日期格式、字体/字号、粗体、文字颜色、填充色及对齐。格式修改写入关联原文件并同步月份副本，保留单元格值与公式，创建备份并检查文件指纹；未关联或历史月份不能保存格式。不支持的格式或非法选区会被拒绝。

## 安装、启动和内网访问

新安装默认目录 `%LOCALAPPDATA%\Programs\labwork`，程序按 `versions/labwork-v版本号` 隔离保存。安装器默认创建当前用户桌面 `labwork` 快捷方式，并创建开始菜单入口；升级后指向当前版本目录中的 `labwork.exe`。双击快捷方式启动托盘，双击托盘打开页面，右键“停止平台并退出”正常退出。图标可能在任务栏“^”隐藏区。

已有稳定产品沿用原安装目录与数据，即使旧目录使用中文名也不强行搬移。数据目录可自定义；安装器拒绝未知已有目录及正在使用的数据目录，不删除旧版本文件。同一数据目录不能同时运行多个实例。升级前正常退出并备份整个数据目录与关联原文件。

程序旁 `labwork.json` 保存 `port`、`data_dir`、`lan_ip`、`access_password`。私网 IP 留空只供本机；启用内网时填写服务器实际10.x、172.16–31.x或192.168.x地址，不能填写0.0.0.0，访问口令须为12–256字符。客户端浏览器访问 `http://服务器IP:端口`。同数据目录升级或重装，口令留空沿用已登记安装配置中的口令，填写新口令则更换；不会在安装页面显示旧口令。新安装、改用其他数据目录或无法读取有效旧配置时需设置口令。口令保存在服务器配置文件，勿共享该文件。

安装页可选择配置内网访问规则，只放行所填本机私网 IPv4、TCP 端口及 `LocalSubnet` 来源。首次创建或更改规则需要 Windows 管理员授权；已存在匹配规则时直接沿用，无需再次授权。取消授权仍可完成安装，内网访问须另行放行。该配置在安装时执行，正常启动程序不重复配置；卸载只清理当前产品自己的规则。若跳过配置，或使用便携包，可由管理员按实际地址与端口手动配置，例如：

```powershell
New-NetFirewallRule -DisplayName 'labwork-LAN' -Direction Inbound -Action Allow -Protocol TCP -LocalAddress 192.168.1.50 -LocalPort 18810 -RemoteAddress LocalSubnet -Profile Any
```

静默安装支持 `/PORT=18810 /DATADIR="D:\LabworkData" /LANIP=192.168.1.50 /ACCESSPASSFILE="D:\临时口令.txt"`，默认 `/FIREWALL=no`；只有明确指定 `/FIREWALL=yes` 才配置内网规则。口令从UTF8文件读取，完成后删除临时文件，避免把口令放入命令行。便携包不包含业务工作簿或数据库，解压双击EXE启动；相对数据路径按EXE目录解析。

勾选“记住登录”保持30天且支持服务器重启；未勾选为12小时会话，重启失效。退出登录或修改口令吊销会话。服务器仅保存会话令牌哈希，浏览器 Cookie 使用 HttpOnly 与 SameSite。

## 回退与验证

旧版本程序及发布目录保留。回退前正常退出，使用升级前备份的独立数据目录，并保留现有原文件与新旧数据；切换EXE不会撤销已写入原文件的结果。grid.5不读取新月份目录，不可把回退旧EXE当成自动无损合并。

Windows 构建需要Rust stable与MSVC，CRT静态链接，用户运行无需开发工具：

```powershell
cargo test --locked
cargo build --release --locked
node tools/grid-test.cjs
```

验收仅使用隔离文件，核对计算/手动值落入真实关联原表、原表已有数据保留、未关联写入拒绝、导入关联回滚、备份/冲突/重试、格式持久化、月份与跨年目录，以及桌面入口安装。以发布目录验收JSON为准。

本版只支持四则运算、括号与单元格引用，不是完整Excel引擎；宏、复杂函数完整重算与WPS原生打开尚未验收；Excel正常打开、列宽与冻结窗格检查以本版发布报告为准。浏览器320/390/768/1440视口模拟不等于真实手机测试。当前使用HTTP及共享口令，适用于可信实验室内网，完整分账号权限和HTTPS尚未完成。

安装端口规则的自动测试使用模拟数据及只读参数集检查；未实际修改生产防火墙或验收管理员授权弹窗。
