# Rust + SQLite 表格验证版 0.0.2-alpha.1-grid.3

本版本修正日期显示，支持多批号计算和表格填充。不是完整 v0.0.2：账号权限、正式内网 HTTPS、原生 Windows 服务和旧版数据迁移仍未完成。程序固定监听 `127.0.0.1:18805`，不能直接用于多人正式检测。

启动后访问：http://127.0.0.1:18805 。旧 alpha.1 的 18802 和 v0.0.1 正式服务独立保留。原表和正式数据库未修改。

Windows安装版从开始菜单“启动理化检测平台（托盘）”启动，双击托盘图标打开18805；图标可能在Windows的“^”隐藏区。右键可打开数据目录或正常停止。18802、18804是旧版，页面顶部的版本及数据目录可用于区分。

历史相邻重复日期/批号也只显示首行，原始值可在公式栏核查。候选Excel同步整理目标表的历史重复标签，确认写入时保存备份。

## 操作

1. 选择 D006 或 Q，再选择方法。目前迁移了这两个项目的 14 个方法，其他项目入口显示待接入。
2. 每行录入日期、批号及一次测定。点击“同批号测定行”新增平行测定，或“新批号”新增一组。新增行数可以一次设置多个，合计最多200行。同组空白日期/批号继承上一行；跨日期时须重新填写批号。
3. 桌面支持 Tab 横向、Enter 纵向、方向键、矩形多格粘贴（从日期、批号或任意输入字段开始），以及选区复制。点击种子单元格，Shift＋点击/方向键扩展矩形；向下拖动选区右下角绿柄，或选择填充终点后点击“向下填充”。复制模式重复种子；递增序列模式支持数值、日期及批号末尾数字，两个种子确定步长。先新增目标行再填充。批量粘贴/填充/增删行可撤销。
4. 手机显示字段卡片：点击字段选择后，使用填充按钮；“选择整行”可复制整个测定。保留原表横向预览。
5. 点击“全部批号计算并预览”，核对结果和绿色拟追加行。服务端按日期及首次出现的批号次序归组；同一天日期只填首行，同批号平行测定批号只填首行，其余留空，**不新增合并**。继续追加相邻的同日/同批号时保持空白标识，每行仍保留结果和备注。不同日期的同批号重新显示批号。
6. 日期以真实 Excel 数值加日期格式写入，网页显示 YYYY-MM-DD，兼容1900/1904日期系统、原表的20261008八位日期和斜杠/点分隔的文字日期。原有数字日期在本方法预览中正确显示，并在确认追加时修正副本中的日期样式。只修正映射的日期列，不改原件。
7. 预览时工作文件未改变，可下载实际候选 XLSX；200行待写入结果全部显示，历史区仍可折叠。
8. 点击“确认写入工作副本”，保存独立副本并自动创建写前备份。重复点击不重复追加；文件变化会提示重新预览。成功后清空已提交输入、准备下一批，避免再次点击计算而重复追加。

程序内置业务方法候选参数，不代表业务核定。原表图片、按钮、条件格式和 Office 编辑器的全部操作尚未在网页重现；无关 XLSX 部件在回写中保持。当前只显示表头与最近记录，最多 A:AN；更宽模板需扩展分页后接入。

## 构建与回归

需要 Rust stable、Windows MSVC 构建工具。用户运行打包程序不需要 Rust、Python 或独立数据库；Windows CRT 静态链接。

```powershell
cd C:\labwork\.worktrees\rust-grid\rust-preview
cargo test --locked
cargo build --release --locked
node tools/grid-test.cjs
```

开发用 `tools/prepare.py` 从旧版定义读取方法并复制两份源工作簿到独立目录；Python只用于开发夹具和对照检查，不随 Rust 验证程序分发。`tools/smoke.py` 启动隔离服务，核对全部 14 方法与旧版 Decimal 输出、ZIP 部件、预览不写、幂等、并发冲突、中断恢复、Host/CSRF 和 SQLite 方法快照。

## 便携包

便携包包含可执行文件、说明和一个空的独立数据目录，**不包含业务工作簿、账号或数据库**。把自己的两份工作簿副本复制到 `data\workbooks\D006.xlsx`、`data\workbooks\Q.xlsx`，再运行“启动预览.cmd”，浏览器访问上述本机地址。程序会创建 SQLite 和预览/备份目录。

默认数据目录不会指向 `C:\ProgramData\Labwork`。不要将测试目录替换为正式数据目录。重新运行使用同一个数据目录可继续查看已保存的预览历史；关闭启动命令窗口中的程序以停止服务。

## 验证边界

14 方法 HTTP/文件回归、批号/日期分组、跨次追加、200行完整预览、1904日期系统、日期样式复用和整批错误拒绝均需通过发布检查；实际结果和二进制/ZIP大小见发布目录。填充和粘贴有 Node 回归。当前浏览器工具未连接，未完成真实浏览器拖动、桌面/手机视觉验收、实际手机设备和 Excel/WPS 重算检查。

## 隔离和回退

源码在 `fix/rust-grid` 分支及 `.worktrees\rust-grid` 工作区，发布标签与旧版独立。主机试用数据从旧 alpha.1 验证目录只读快照到新的 `runtime\rust-grid-data`，旧目录、旧18802进程、未完成的账号迁移源码都保留。回退只需关闭当前验证程序并访问旧18802页面；两个验证版本的后续输入各自保存，不会自动相互同步。
