# Rust + SQLite 表格验证版 0.0.2-alpha.1-grid.5

本版本修正日期显示，支持多批号计算和表格填充。默认监听 `127.0.0.1:18807`；安装时可设置端口，填写服务器固定私网 IPv4 和至少12字符共享口令后启用局域网模式。其他电脑和手机用浏览器访问 `http://服务器IP:端口`。本版的分账号权限、HTTPS、原生 Windows 服务和旧版数据迁移仍未完成。

启动后访问：http://127.0.0.1:18807 。旧 alpha.1 的 18802 和 v0.0.1 正式服务独立保留。原表和正式数据库未修改。

Windows安装版从开始菜单“启动理化检测平台（托盘）”启动，双击托盘图标打开18807；图标可能在Windows的“^”隐藏区。右键可打开数据目录或正常停止。18802、18804是旧版，页面顶部的版本及数据目录可用于区分。

历史相邻重复日期/批号也只显示首行，原始值可在公式栏核查。候选Excel同步整理目标表的历史重复标签，确认写入时保存备份。

## 操作

1. 选择 D006 或 Q，再选择方法。目前迁移了这两个项目的 14 个方法，其他项目入口显示待接入。
2. 每行录入日期、批号及一次测定。点击“同批号测定行”新增平行测定，或“新批号”新增一组。新增行数可以一次设置多个，合计最多200行。同组空白日期/批号继承上一行；跨日期时须重新填写批号。
3. 桌面支持 Tab 横向、Enter 纵向、方向键、矩形多格粘贴（从日期、批号或任意输入字段开始），以及选区复制。点击种子单元格，Shift＋点击/方向键扩展矩形；向下拖动选区右下角绿柄，或选择填充终点后点击“向下填充”。复制模式重复种子；递增序列模式支持数值、日期及批号末尾数字，两个种子确定步长。先新增目标行再填充。批量粘贴/填充/增删行可撤销。
4. 手机显示字段卡片：点击字段选择后，使用填充按钮；“选择整行”可复制整个测定。保留原表横向预览。
5. 点击“全部批号计算并预览”，核对结果和绿色拟追加行。服务端按日期及首次出现的批号次序归组；同一天日期只填首行，同批号平行测定批号只填首行，其余留空，**不新增合并**。继续追加相邻的同日/同批号时保持空白标识，每行仍保留结果和备注。不同日期的同批号重新显示批号。
6. 日期以真实 Excel 数值加日期格式写入，网页显示 YYYY-MM-DD，兼容1900/1904日期系统、原表的20261008八位日期和斜杠/点分隔的文字日期。原有数字日期在本方法预览中正确显示，并在确认追加时修正副本中的日期样式。只修正映射的日期列，不改原件。
7. 预览时工作文件未改变，可下载实际候选 XLSX；200行待写入结果全部显示，历史区仍可折叠。
8. 点击“确认写入工作副本”，保存独立副本并自动创建写前备份。重复点击不重复追加；文件变化会提示重新预览。成功后清空已提交输入、准备下一批，避免再次点击计算而重复追加。

程序内置业务方法候选参数，不代表业务核定。原表图片、按钮、条件格式和 Office 编辑器的全部操作尚未在网页重现；无关 XLSX 部件在回写中保持。当前只显示表头与最近记录，最多 A:AN；更宽模板需扩展分页后接入。

## 构建与回归

需要 Rust stable、Windows MSVC 构建工具。用户运行打包程序不需要 Rust、Python 或独立数据库；Windows CRT 静态链接。

```powershell
cd C:\labwork\.worktrees\rust-grid\rust-preview
cargo test --locked
cargo build --release --locked
node tools/grid-test.cjs
```

开发用 `tools/prepare.py` 从旧版定义读取方法并复制两份源工作簿到独立目录；Python只用于开发夹具和对照检查，不随 Rust 验证程序分发。`tools/smoke.py` 启动隔离服务，核对全部 14 方法与旧版 Decimal 输出、ZIP 部件、预览不写、幂等、并发冲突、中断恢复、Host/CSRF 和 SQLite 方法快照。

## 便携包

便携包包含可执行文件、说明和一个空的独立数据目录，**不包含业务工作簿、账号或数据库**。双击 labwork-preview.exe（默认托盘启动）后，在页面选择项目并使用“导入工作簿”上传对应 XLSX 副本；也可手工复制到 `data\workbooks\D006.xlsx`、`data\workbooks\Q.xlsx`。程序会创建 SQLite 和预览/备份目录。

默认数据目录不会指向 `C:\ProgramData\Labwork`。不要将测试目录替换为正式数据目录。重新运行使用同一个数据目录可继续查看已保存的预览历史；右键托盘选择“停止平台并退出”以停止服务。

## 验证边界

14 方法 HTTP/文件回归、批号/日期分组、跨次追加、200行完整预览、1904日期系统、日期样式复用和整批错误拒绝均需通过发布检查；实际结果和二进制/ZIP大小见发布目录。填充和粘贴有 Node 回归。当前浏览器工具未连接，未完成真实浏览器拖动、桌面/手机视觉验收、实际手机设备和 Excel/WPS 重算检查。

## 隔离和回退

源码在 `fix/rust-grid` 分支及 `.worktrees\rust-grid` 工作区，发布标签与旧版独立。主机试用数据从旧 alpha.1 验证目录只读快照到新的 `runtime\rust-grid-data`，旧目录、旧18802进程、未完成的账号迁移源码都保留。回退只需关闭当前验证程序并访问旧18802页面；两个验证版本的后续输入各自保存，不会自动相互同步。

## 安装配置

中文安装器提供端口（默认18807）和可选数据目录；留空使用固定安装根目录的 data。配置写在程序旁的 labwork.json，卸载保留数据。双击程序直接托盘启动，无需命令窗口。便携包中的相对 data 路径按程序目录解析。静默安装支持 `/PORT=18807 /DATADIR="D:\LabworkData"`；已有目录必须带平台标记，未知目录会拒绝安装。数据目录须位于本机磁盘。

## 局域网访问

安装页面的“服务器固定私网 IPv4”填写本机实际的 10.x、172.16–31.x 或 192.168.x 地址；留空则仅本机。填写地址时必须设置至少12字符访问口令，客户端通过 `http://服务器IP:端口` 登录。Windows 防火墙规则由管理员按安装说明添加，使用 `-Profile Any -LocalAddress <实际服务器私网IP> -RemoteAddress LocalSubnet`，仅放行指定私网IP和同网段来源，无需修改当前网络类型，安装器不会提权更改防火墙。

`labwork.json` 新增 `lan_ip`、`access_password`；口令在本地配置保存，勿共享此配置文件。静默安装采用 `/LANIP=192.168.1.50 /ACCESSPASSFILE="D:\临时口令.txt"`，口令不放命令行和安装日志。局域网同版本重装需重新输入口令。HTTP与共享口令只适用于可信实验室内网。

安装与旧版衔接：固定根目录为 %LOCALAPPDATA%\Programs\理化检测平台，程序位于 versions\版本号，默认数据在根目录 data。升级复用同一产品安装位置和设置，保留旧版本程序文件。安装器发现旧 grid.3/grid.4 后会提示其路径；先从旧版托盘退出，再在数据目录栏选择旧安装目录的 data（若旧版自定义过目录则选择原自定义目录），即可继续使用已有记录；这一步是选择既有目录，不是复制迁移或覆盖文件。旧安装目录及旧卸载项保留，新版不删除旧数据。正在使用的数据目录会拒绝安装。回退前退出当前实例，再运行保留的旧版本 EXE；同一数据目录不能同时运行多个实例。

首次从旧 grid.3/grid.4 升级时，默认把新的中文产品目录设在旧安装目录的同级；检测到带平台标记的旧 data 会预填为数据来源，不复制或覆盖。已安装新产品后继续沿用其安装位置和设置。选择全新的独立数据目录不要求停止无关旧实例；如选择旧版自定义目录，必须手动确认旧实例已退出。口令长度为12至256字符。
