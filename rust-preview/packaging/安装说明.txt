理化检测平台 Rust 验证版 0.0.2-alpha.1-grid.4

中文 Windows 安装器支持选择本机端口和数据目录。
端口默认 18806，范围 1024–65535，仅监听 127.0.0.1。
数据目录留空时使用本版本安装目录的 data；可指定本地磁盘绝对路径。
安装器拒绝没有平台标记的已有目录，避免误用未知数据。
请不要选择其他正在运行的实例的数据目录。

安装后使用：
1. 从开始菜单打开“工作簿副本目录”。
2. 把 D006、Q 工作簿的副本放入该目录，命名为 D006.xlsx、Q.xlsx。
   安装包不含业务工作簿，不会自动搬动现有记录。
3. 双击 labwork-preview.exe 或开始菜单的“启动理化检测平台（托盘）”。
   无需 CMD 窗口；图标可能收入 Windows 任务栏的“^”隐藏图标区。
4. 双击托盘图标或右键“打开平台”，会按实际配置打开正确端口。
5. 右键托盘选择“停止平台并退出”，等待图标消失后再升级或卸载。

配置保存在程序旁的 labwork.json，记录 port 和 data_dir。
默认访问：http://127.0.0.1:18806；自定义端口以托盘打开的地址为准。
便携包直接解压并双击程序，配置中的相对 data 路径按程序目录解析。
静默安装支持 /PORT=18806 /DATADIR="D:\LabworkData"。
端口冲突时先退出冲突实例，或修改配置后重新启动。

各版本独立安装；卸载保留数据目录、数据库、工作簿和备份。
升级或回退前备份整个数据目录，不同版本后续数据不会自动同步。
默认安装不需要管理员权限；外部目录必须有当前用户写入权限。
安装包不注册 Windows 服务，不设置开机启动，不开放局域网端口。
本版仍用于本机验证；完整内网账号权限、HTTPS 和服务迁移尚未完成。
实际手机、浏览器拖动及 Excel/WPS 重算尚未验收。
