理化检测平台 Rust 验证版 0.0.2-alpha.1-grid.2

这是中文 Windows 安装包，安装当前 Rust 表格修订版。
本版本用于本机验证，包含日期修正、多批号计算和表格填充功能。
访问地址：http://127.0.0.1:18804

安装后使用：
1. 从开始菜单打开“工作簿副本目录”。
2. 把 D006、Q 的工作簿副本分别放入该目录，命名为 D006.xlsx、Q.xlsx。
   安装包不包含业务工作簿，不会自动搬动现有记录。
3. 从开始菜单点击“启动理化检测平台”，保留启动窗口。
4. 点击“打开平台页面”，用浏览器录入和预览。
5. 停止时在启动窗口按 Ctrl+C；随后可关闭窗口。

若提示端口被占用：18804 上已有 Rust 验证程序运行。
请先停止旧验证程序，再启动本次安装的版本，以免进入另一份数据目录。
原正式平台的 8443 和旧验证版的 18802 不受本安装影响。

版本与数据：
默认安装到当前用户目录，不需要管理员权限。
每个版本独立安装，数据在安装目录的 data 子目录。
卸载保留 data 内的数据库、工作簿和备份，请自行妥善保存。
升级或回退之前备份整个 data 目录；不同版本的数据不会自动同步。
安装包不注册 Windows 服务，不设置开机启动，不开放局域网端口。
完整内网账号权限、HTTPS 和服务迁移尚未完成。

当前检测计算和文件回写已通过回归；实际手机、浏览器拖动及 Excel/WPS 重算尚未验收。
