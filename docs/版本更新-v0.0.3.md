# labwork-v0.0.3

本版安装包固定为 `labwork-v0.0.3.exe`，版本号不再带 alpha、grid 等后缀。程序为 `labwork.exe`，发布、安装版本目录和 Git 标签均为 `labwork-v0.0.3`。旧安装包与版本目录保留，已有配置和数据目录继续沿用。

工作簿管理增加“删除导入项目”，用于清理误导入或重复的目录项目。操作仅影响当前可录入月份，平台工作副本归档，服务器原文件、旧月份和写入历史保留；尚未完成的写入须先处理。“解除关联”保留项目，仅停止原文件写入，并可重新关联。两项操作在页面单独说明并要求确认，原文件路径仍由使用者自行设置。

“新建月份”先生成实际空白模板预览，可切换项目及工作表检查清空后的内容、保留区域和目标路径。预览不创建月份或源文件，确认后才生成。原文件、关联或清空规则在预览后变化时拒绝生成，要求重新预览。新模板按确认范围清空日期、批号、测定输入及结果，保留表头、格式、公式和固定参数，跨年继续按项目/年/月目录继承；已存在目标文件不覆盖。

继续保留已知 Excel 命名空间损坏的拒写检查，结果写入、选区格式修改及月份模板生成共用格式保护。已经损坏的文件不会因安装新版自动恢复；须先另存并核对写入前备份与新增记录。

发布门禁核对最终程序的 API、页面、项目移除、月份预览、文件不改写、原始布局、原生 Excel 普通打开和中文安装验收。测试使用隔离目录与独立安装登记，真实源文件、安装登记和桌面入口不修改。具体结果及程序 SHA256 附在发布目录 JSON。

升级前从托盘正常退出，备份数据目录和关联源文件。安装后桌面 `labwork` 快捷方式指向本版；回退使用旧程序和升级前备份的独立数据目录，切换程序不会撤销写入到源文件的结果。WPS 原生打开、真实手机设备和完整复杂公式重算未验收。
