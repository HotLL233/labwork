# 表格修订版 grid.5

本版本新增局域网模式及页面导入工作簿。默认端口18807；安装时填写服务器实际固定私网IPv4并设置至少12字符访问口令即可启用内网模式，IP留空则只供本机访问。其他电脑和手机通过浏览器访问服务器地址。

配置写在程序旁 labwork.json，包括 port、data_dir、lan_ip 和 access_password。共享口令仅保存在服务器本地，不通过页面或日志回显。卸载保留数据；grid.4及更旧版本独立保留。安装器不自动提权配置防火墙，操作命令见安装说明。

安装回归覆盖配置、实际本机启动、数据保留、非法端口/地址拒绝、内网口令要求及口令不出现在安装日志。验收以发布目录安装验收.json为准。

本版本使用HTTP及共享访问口令，限可信实验室内网；完整分账号权限、HTTPS及正式服务迁移尚未完成。

安装与旧版衔接：固定根目录为 %LOCALAPPDATA%\Programs\理化检测平台，程序位于 versions\版本号，默认数据在根目录 data。升级复用同一产品安装位置和设置，保留旧版本程序文件。安装器发现旧 grid.3/grid.4 后会提示其路径；先从旧版托盘退出，再在数据目录栏选择旧安装目录的 data（若旧版自定义过目录则选择原自定义目录），即可继续使用已有记录；这一步是选择既有目录，不是复制迁移或覆盖文件。旧安装目录及旧卸载项保留，新版不删除旧数据。正在使用的数据目录会拒绝安装。回退前退出当前实例，再运行保留的旧版本 EXE；同一数据目录不能同时运行多个实例。

首次从旧 grid.3/grid.4 升级时，默认把新的中文产品目录设在旧安装目录的同级；检测到带平台标记的旧 data 会预填为数据来源，不复制或覆盖。已安装新产品后继续沿用其安装位置和设置。选择全新的独立数据目录不要求停止无关旧实例；如选择旧版自定义目录，必须手动确认旧实例已退出。口令长度为12至256字符。
