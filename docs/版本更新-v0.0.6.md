# labwork-v0.0.6

本版修正录入界面和计算/写入预览的历史行折叠。原表预览与写入候选均从第一行到末行按行号连续显示，保留中间历史记录和空白行，便于对照原 Excel 表格核对结果。

每次最多200行测定、只读工作表浏览和月份模板每页最多200行分页继续保留。原文件关联、解除关联、删除导入、新建月份空白模板、格式保护、升级口令沿用和可选内网端口配置沿用上一版。

安装包固定为 `labwork-v0.0.6.exe`，程序为 `labwork.exe`，发布目录、安装版本目录与标签为 `labwork-v0.0.6`。历史发布和旧版本程序保留；升级前从托盘正常退出，备份整个数据目录与关联原文件，升级后重新生成预览。

发布验收须绑定最终 EXE 的 SHA256，并核对原表与候选的行号连续性、原文件写入、空白模板、原始布局、原生 Excel 和浏览器流程。增强安装验收继续使用独立 AppId、隔离数据目录及 `/FIREWALL=no`，不覆盖真实安装或操作生产防火墙。具体结果以发布目录报告为准。

管理员授权弹窗、WPS 原生、实体手机及复杂公式完整重算未验收。
