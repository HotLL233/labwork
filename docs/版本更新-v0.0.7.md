# labwork-v0.0.7

本版精简工作表上方的操作区：去除重复标题和说明，合并计算与录入工具栏并缩小间距，让表格更早显示，便于直接录入和核对结果。

在1440像素宽的浏览器中，首个输入字段距页顶由600.25像素降至390.80像素，减少约209像素；手机主操作按钮保留44像素高度。具体测量及对照截图附在发布目录。

原表和计算/写入预览继续按行号显示全部行，保留中间历史记录和空白行。每次最多200行测定、只读工作表浏览和月份模板每页最多200行分页继续保留。原文件关联、解除关联、删除导入、新建月份空白模板、格式保护、升级口令沿用和可选内网端口配置沿用上一版。

安装包固定为 `labwork-v0.0.7.exe`，程序为 `labwork.exe`，发布目录、安装版本目录与标签为 `labwork-v0.0.7`。历史发布和旧版本程序保留；升级前从托盘正常退出，备份整个数据目录与关联原文件，升级后重新生成预览。

发布验收须绑定最终 EXE 的 SHA256，核对操作区布局、原表与候选的行号连续性、原文件写入、空白模板、原始布局、原生 Excel 和浏览器流程。增强安装验收继续使用独立 AppId、隔离数据目录及 `/FIREWALL=no`，不覆盖真实安装或操作生产防火墙。具体结果以发布目录报告为准。

管理员授权弹窗、WPS 原生、实体手机及复杂公式完整重算未验收。
