# labwork-v0.0.5

本版修正升级时反复输入访问口令的问题。同一数据目录升级或重装，口令留空时沿用已登记安装配置中的口令；填写新口令时更换，旧口令不在安装页显示。新安装、改用其他数据目录或旧配置无效时需要设置内网口令。口令保存在服务器配置中，不放入命令行或安装日志。

安装页可选择一次性配置内网端口规则，仅放行指定本机私网 IPv4、TCP 端口及 `LocalSubnet` 来源。首次创建或更改规则需要 Windows 管理员授权；已有匹配规则时直接沿用，无需再次授权。取消授权仍可完成安装，内网访问须另行放行。正常启动程序不重复执行网络配置；卸载只清理当前产品自己的规则。静默安装默认 `/FIREWALL=no`，明确 `/FIREWALL=yes` 才配置；跳过配置或使用便携包时，可由管理员手动配置。

安装包固定为 `labwork-v0.0.5.exe`，程序为 `labwork.exe`，发布目录、安装版本目录与标签为 `labwork-v0.0.5`。历史发布和旧版本程序保留；升级前从托盘正常退出，并备份整个数据目录与关联原文件。

工作簿原文件关联、删除导入、解除关联、新月份空白模板预览、选区清空调整及格式保护沿用上一版。新版本不会自动恢复过去损坏的工作簿；旧预览在升级后须重新生成。

发布前须以最终 EXE 的 SHA256 绑定原文件写入、模板预览、原始布局、原生 Excel、浏览器与安装验收报告；安装设置及网络辅助脚本还需绑定脚本哈希。中文安装验收使用独立 AppId 和隔离数据目录，检查升级口令、快捷方式与数据保留，不覆盖真实安装。网络规则自动检查使用模拟数据及只读参数集检查，未实际修改生产防火墙或验收管理员弹窗。具体结果以发布目录报告为准。

WPS 原生、实体手机及复杂公式完整重算仍未验收。
