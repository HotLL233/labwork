# 表格修订版 0.0.2-alpha.1-grid.2

本次范围是用户反馈的日期、日期/批号只填首行、多批号同时计算、下拉填充。基于已验证 alpha.1 独立修订，不覆盖 `feature/rust-excel` 工作区中正在进行的账号与记录迁移。

## 日期和分组

- 原模板日期列使用常规格式，旧代码写入数字日期后被显示为Excel序号。新写入日期沿用原字体/边框并使用日期格式，网页按方法的日期列映射显示 YYYY-MM-DD。
- 兼容1900与1904日期系统，保留1900闰年兼容规则；只修正当前方法副本的日期样式。
- 原表同时存在20261008八位日期、Excel序号和文字日期。按日期列映射统一显示，并保留原始值供公式栏核对；数字八位日期确认写入时转换为同一天的标准日期值，文本原日期保持。
- 同日日期只填首行，同批号平行测定批号只填首行，其余留空，不新增合并。不同日期的同批号重新标注批号。
- 每行完整保存日期、批号、测定与备注到SQLite快照；Excel空白标识只是显示规则，不丢失行归属。
- 服务端把同日同批号归组后生成唯一候选文件，显示顺序以绿色预览为准；各结果保留对应原始测定。
- 继续追加与末尾相邻的同日/同批号可继续留空。若回到历史日期或历史非相邻批号，则形成新段并重新标注，避免空白行被误认作当前段的其他批号；本版不搬动历史记录。

## 批量和填充

每次1至200行。桌面原表与独立录入表共享数据，手机显示每行的字段卡片。支持新增同批号测定行/新批号、多格粘贴、Tab/Enter/方向键、矩形选择和选区复制。

桌面点击单元格，以Shift＋点击或Shift＋方向键选择种子范围，再拖动右下角绿柄向下填充。复制模式重复种子，递增序列模式支持日期、数值和批号末尾数字；两个种子按差值确定步长。先新增目标行再填充。手机使用“向下填充”/“填充至末行”按钮。批量操作可撤销。

预览显示全部待写行，避免200行批量只显示末尾13行。任一测定无效，整批拒绝，文件保持原样。写入后准备空的新行，避免再次计算而误追加已提交数据。
