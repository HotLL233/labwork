# labwork 表格修订版 grid.9

grid.8 上传仅创建月份副本，关联路径为空时确认仍能显示“已保存”，不能满足把结果写入服务器原文件的目标。grid.9 以关联原文件为录入依据，未关联时禁止确认写入与保存格式，并提供直接进入关联设置的入口。

已有项目无需再导入。例如已有 EF1，选中 EF1 和当前月份，点击“关联原文件”进入管理，在“关联当前项目原文件”自行填写服务器本机现存 XLSX 绝对路径，点击“关联此项目原文件”，然后重新预览、“确认写入原文件”。关联本身不修改文件，路径由使用者在页面配置，程序不硬编码业务文件路径。

新项目可在“关联服务器工作簿 · 新项目”中“关联并生成目录”，一次导入并关联。上传客户端副本仍需后续关联；浏览器无法得到原文件绝对路径。已存在项目、重复关联、非法文件拒绝处理，失败不留未关联项目或残余绑定。

读取、公式识别与预览使用关联原文件的最新内容。计算结果或手动值在保留原文件既有记录的基础上追加，然后同步月份镜像。预览后原文件发生变化则拒绝覆盖；写前备份，锁定造成同步中断可从历史重试同一次写入，避免重复追加。保存行高、列宽、数字/日期、颜色和对齐使用同一备份、指纹及同步保护。

升级前只写入月份副本的记录不会自动合并进原表。先下载保留旧副本，核对需补录记录后重新录入；关联后的依据是原文件，不能让旧副本整本覆盖原文件已有数据。旧版未确认预览须重新生成；旧版未完成写入保留文件与备份并要求核对，不直接覆盖原文件。

新月份继续按项目/年份/月目录生成并关联空白原文件。跨年创建对应年份目录，既有目标文件不覆盖，历史文件保留。默认端口18810，升级沿用原设置，安装包名使用labwork，并保留自动桌面快捷方式和版本隔离。

验收仅使用隔离副本，覆盖未关联拒绝、一次导入关联回滚、手动及计算结果落入原文件、原文件独有记录保留、预览前后外部修改、备份与锁恢复、格式持久化、月份及跨年目录。浏览器模拟移动端与安装验收以发布目录报告为准；不表示Excel/WPS原生重算或真实手机设备已验收。
