# 表格修订版 grid.3：托盘和旧记录标签修复

用户截图为 `127.0.0.1:18802` 的 alpha.1 旧版。grid.2 程序在18804，并且此前安装包只启动控制台，没有托盘。

本修订版本是 `0.0.2-alpha.1-grid.3`，使用独立本机地址 `http://127.0.0.1:18805`，避免与旧版混淆。页面顶部显示版本、端口和实际数据目录。

## 使用

安装后从开始菜单选择“启动理化检测平台（托盘）”。原生Windows图标显示在任务栏通知区域，可能被Windows放入“^”隐藏图标区。悬停显示版本和18805；双击或右键“打开平台”进入新页面；右键“打开数据目录”访问当前副本；“停止平台并退出”发送正常停止信号，等请求结束后清理图标。

端口已被占用时显示错误，不打开其他实例页面。旧18802、18804和正式8443均保留，数据目录独立。

## 日期、批号

历史记录中的Excel日期序号、八位日期和文字日期统一显示。相邻同日重复日期、同日同批号重复批号只显示首行，后续留空，不合并；日期变化时重新显示批号。原始值保留在公式栏，便于核查。表尾预览同时带出所属组首行，避免折叠后看不到日期和批号。

生成新候选Excel时，同步整理目标表中的历史常量重复标签；原有计算结果、公式和合并结构保留。预览不写文件，确认写入才替换工作副本并保存备份。新批量计算/填充功能沿用grid.2。
