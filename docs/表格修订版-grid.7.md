# labwork 表格修订版 grid.7

项目名称统一为labwork，安装界面保持中文。安装包为labwork-0.0.2-alpha.1-grid.7-Windows-x64-Setup.exe，默认端口18810。

新安装默认目录和开始菜单使用labwork；既有稳定产品沿用原安装目录与数据，不因品牌改名搬动用户目录。升级保留versions中的旧程序，统一当前开始菜单入口，只清理已知旧快捷方式，不删除工作簿或数据库。

本轮原表识别123个可录入方法，按原表提取输入、参数与四则公式；11张目录表用于导航。FPO/Sheet1、RD05/硼酯、RD05/三氟苯基溴化镁缺日期列，当前只读。公式支持四则、括号与单元格引用，不是完整Excel引擎。检测与管理入口分开，手机字段卡片及固定操作区更紧凑。勾选记住登录有效30天且跨服务器重启；不勾选为12小时会话且重启失效，退出登录或改口令吊销会话。月份目录、历史月只读、未知表清空范围确认与升级前完整备份要求继续适用。grid.6及旧版产生的数据不会因程序回退而自动合并。

安装验收使用与正式安装器同源的独立QA AppId，避免覆盖已安装产品注册与数据；QA跳过真实旧品牌快捷方式迁移。正式安装器仍使用稳定AppId。实际结果见安装验收JSON。

浏览器回归覆盖320/390/768/1440视口及实际预览、确认写入；截图随发布保存。托盘注册与清理自动测试通过，尚未进行托盘人工视觉和Excel/WPS原生重算验收。

月份规则升级：本版使用 month-rules-v2.json，保留旧规则文件供回退。升级后首次新建月份前必须重新确认清空范围，不能直接沿用旧规则，以免旧规则漏清输入或结果；确认后保留固定表头、参数、格式和公式，并清除本次确认的数据区域。
