# labwork-v0.0.4

本版修正新月份模板预览，并简化此前需逐表确认清空规则的流程。点击“新建月份并预览”后，平台自动准备模板，可切换项目和工作表查看实际内容、上月原值、清空标记及目标路径。有效的旧规则继续使用；结构变更时重新识别，未知表与目录表默认保留。

含暂不支持公式或无法识别数据区的表默认保留原值，可在预览中显式选区清空。

如需调整，在预览表格选择区域，点击“清空选区”或“保留原值”，再检查模板；可撤销调整。公式、已识别固定参数、前两行及目录表受保护。预览和取消均不创建月份或改写源文件；确认时再次校验原文件、目录、规则和选区调整，变化后须重新预览。

已按项目/年/月保存的源文件沿用原目录层级。直接放在普通文件夹中的源文件也可预览，并推导安全的项目/年/月目标。目标文件已存在等阻断问题会显示在预览中，模板仍可检查，确认生成保持禁止覆盖。

工作簿管理继续支持“解除关联”和“删除导入项目”。删除只移除当前月份目录并归档平台副本，源文件、旧月份、写入历史和备份保留。源文件路径仍由使用者配置。已知 Excel 格式结构损坏继续拒绝写入；新版不会自动修复已经损坏的旧文件。

安装包固定为 `labwork-v0.0.4.exe`，程序为 `labwork.exe`，发布目录、安装版本目录与标签为 `labwork-v0.0.4`。安装支持自定义端口、数据目录、服务器私网 IPv4 及访问口令；保留历史发布和旧版本，升级前从托盘正常退出并备份数据目录与关联原文件。

发布验收绑定最终程序 SHA256，包含自动模板、选区调整、目标冲突、指纹过期、文件不改写、原始布局、原生 Excel 普通打开、移动视口及中文安装。仅使用隔离目录和独立安装登记，不修改真实源文件、数据库、安装登记或桌面入口。具体报告附在发布目录。WPS 原生打开、真实手机和完整复杂公式重算未验收；自动识别未知表时默认保留，确认前须核对模板。
