# labwork 命名规范

项目名固定为小写 `labwork`。从 v0.0.3 开始，版本号只使用三段数字 `主版本.次版本.修订号`，例如 `0.0.3`；不使用 `alpha`、`grid` 等附加后缀。版本产品名称为 `labwork-v{版本号}`。

| 项目 | 命名 |
| --- | --- |
| Windows 安装包 | `labwork-v{版本号}.exe` |
| Windows 主程序、桌面入口 | `labwork.exe`、`labwork` |
| 发布目录 | `releases/labwork-v{版本号}/` |
| 安装版本目录 | `labwork/versions/labwork-v{版本号}/` |
| 便携包 | `labwork-v{版本号}-Windows-x64.zip` |
| 源码包 | `labwork-v{版本号}-Source.zip` |
| Git 发布标签 | `labwork-v{版本号}` |

历史已发布版本保留原名及位置以便回退；原始工作簿仍使用用户自己的文件名。升级识别、现有数据目录和数据库沿用已有兼容约定，不通过改名迁移业务数据。
