# labwork-v0.0.9

“关联总文件夹”改为页面内选择服务器目录。点击选择按钮，从磁盘逐级进入文件夹，确认当前文件夹后扫描；电脑和手机使用同一入口，不需要输入路径。展示的路径始终属于运行 labwork 的服务器。

扫描结果支持按项目、月份、文件名和路径搜索，并逐项勾选。能够明确识别项目与月份的工作簿可关联；无法识别、内容冲突或不需要的文件可以跳过，不阻挡其他已选文件。同一项目同一月份有多本候选时只能选择一本，确认时重新核对文件指纹，未勾选文件不建立关联。重复关联和旧路径迁移继续检查现有项目、文件内容及工作表结构，不猜测覆盖。

原表预览支持直接编辑常量单元格，也可修改尚未写入的计算预览。编辑内容先保留在页面，生成单元格修改预览后核对，再确认写入关联原文件和月份副本。公式单元格保留算式，通过修改输入重新计算；未知公式不作为已完成的服务端计算结果展示。未关联或历史月份不能写入。切换项目、工作表、月份前处理未确认修改，避免静默丢失。

编辑和普通写入沿用源文件指纹、写前备份、预览校验及中断恢复。保留原表行高、列宽、冻结窗格、合并、字体、颜色、数字格式和打印设置；只有主动保存选区格式时才更改对应格式。已受损原表仍需从写前备份核对恢复，不会通过升级自动重建过去丢失的格式。

保留新月份空白模板预览、公式空输入显示空白、紧凑顶部、全部连续历史行、手机布局、登录保持及升级配置沿用。版本隔离目录为 `labwork-v0.0.9`，中文安装包固定为 `labwork-v0.0.9.exe`；旧版本和旧发布包保留。

最终程序通过24项Rust测试、12组API回归（包括28项目录关联、20项单元格编辑检查）、45项真实浏览器检查和33项隔离安装检查。12本工作簿的138个工作表预览及12次副本源文件确认写入通过；原生Excel正常打开138个预览文件，178页布局中的列宽、既有行高和冻结窗格与原表一致。另验证直接编辑、计算候选再编辑、日期系统、批号前导零、必要公式缓存更新和连续两个月的空白公式行为。所有报告绑定最终EXE的版本及SHA256。

安装验收使用独立AppId、隔离数据和 `/FIREWALL=no`，未修改真实安装、桌面入口、业务原表或防火墙。原生Excel验收仅操作独立副本，测试实例正常退出，不连接或关闭用户已有的Excel实例。

WPS、实体手机、管理员授权弹窗及全部工作簿复杂公式的完整重算未验收。
