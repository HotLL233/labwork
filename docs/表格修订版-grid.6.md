# 表格修订版 grid.6

默认端口18809；稳定安装产品目录、版本隔离、中文安装页面、托盘与局域网配置继续沿用。

本版本支持导入XLSX自动生成项目和工作表目录。已接入计算的仍为D006/Q的14个方法，其他工作表按原表浏览，不自动推断业务算法。页面使用更紧凑的录入与预览布局。

按月份管理工作簿。用户点击新建月份并确认后，复制上月模板，保留格式、公式及参数，清除日期、批号、输入与结果。未知工作表需要一次确认清空范围；历史月只读。

工作文件位于data/months/YYYY-MM/workbooks，首次从旧root/workbooks复制至首个月份，原件保留。后续月份写入不会回同步旧目录。升级前必须停止平台并备份完整数据；回退grid.5时使用升级前备份的独立目录，grid.6产生的新记录需要另外核对，不能视为无损回退。

安装验收继续核对配置、实际HTTP启动、卸载保留数据、版本文件保留、运行数据拒绝、私网地址与口令规则。实际结果以发布目录的验收JSON为准。

本版使用HTTP与共享口令，限可信内网；完整分账号权限、HTTPS及真实手机/Office重算验收仍未完成。
