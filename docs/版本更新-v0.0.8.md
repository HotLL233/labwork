# labwork-v0.0.8

在“关联总文件夹”填写服务器本机的总目录绝对路径，点击“扫描文件夹”。平台按“总目录 / 项目 / 年份 / 月份 / XLSX”识别项目和月份，先展示每个文件的完整路径、识别结果与冲突，点击确认后才导入并关联。扫描和建立关联均不修改原文件，首次平台副本与原文件字节一致。浏览器上传仍只是可选的副本入口。

例如 `全部项目/EF-理化/2026/2026.07/EF-理化-202607.xlsx`；年份也支持 `2026年`，月份支持 `2026-07`、`07`、`7月`。仅识别 XLSX；忽略 Excel 临时锁文件及备份。路径须在服务器本机，网络共享、目录链接和平台数据目录不能作为总目录。项目或月份歧义、同项目同月多个文件会阻止整批确认，不会只导入一部分。

已有项目和月份沿用，重复扫描确认不会增加重复项目。旧文件搬入总目录后，仅在文件指纹与原关联或平台副本一致、工作表结构相同时显示“待迁移关联”；确认只更新关联路径。内容不同的文件不会被猜测为同一个项目，须先核对冲突。当前项目仍保留重新关联原文件、解除关联及删除导入入口；解除或删除导入不会删除服务器原文件及旧月份。

“新建月份并预览”沿用同样的项目/年份/月目录，跨年自动生成新年份目录。清空已识别录入区时，计算列也显示空白，但保留公式、表头、固定参数及原表格式；输入齐全后恢复计算，零值正常参与计算，真实除零仍显示错误。未知公式或无法识别的表默认保留，仍可在预览中检查和调整。预览与取消均不写文件，确认前复验原文件和模板指纹，目标存在时禁止覆盖。

普通写入及新月份生成只改变数据和必要的空白保护公式，保留原表行高、列宽、冻结窗格、合并单元格、字体、颜色、数字格式和打印设置；只有主动保存选区格式时才改变对应格式。写前备份与损坏文件拒写继续保留。已受损文件须用写入前备份核对恢复，升级不会自动重建过去丢失的格式。

保留 v0.0.7 的紧凑顶部、全部连续历史行、计算/写入预览、手机布局及登录保持，不增加折叠操作。

安装包固定为 `labwork-v0.0.8.exe`，程序为 `labwork.exe`，发布目录、安装版本目录与标签为 `labwork-v0.0.8`。历史发布和旧版本程序保留；升级前从托盘正常退出，备份整个数据目录与关联原文件，升级后重新生成预览。

发布验收绑定最终 EXE 的 SHA256，保留原文件写入、布局、连续行、空白模板、原生 Excel、浏览器与安装的既有门禁，增加总目录扫描不写入、批量失败回滚、迁移关联、重复确认，以及原生 Excel 空白计算列与填写后重算检查。安装验收使用独立 AppId、隔离数据目录及 `/FIREWALL=no`，不覆盖真实安装或操作生产防火墙。具体结果以发布目录报告为准。
