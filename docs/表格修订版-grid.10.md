# labwork 表格修订版 grid.10

旧版写入重建工作表 XML 时会丢失命名空间限定属性，导致 Excel/WPS 无法正确读取链接、兼容性信息等；追加单元格还会遗漏原空格属性，新增行未完整继承行高及样式。这些问题可能表现为打开文件提示修复，或者写入后的格式不一致。

grid.10 在共同的 XML 写入路径保留限定属性和原有结构。计算或手动结果回写仅改变目标单元格值及必要范围，冻结窗格、选区、固定列宽、合并、打印设置、链接和历史单元格保持；原有空单元格沿用原属性，新增行继承样式与行高。格式设置仍只改变使用者选择的项目，新建月份继续保留模板结构。

追加日期沿用原表的日期格式和存储方式，普通录入不改写历史日期或全表样式。原表以 General 保存 YYYYMMDD 时继续采用该方式；主动设置日期显示格式时，仅将日期列内的有效八位数字转换为工作簿对应的 Excel 日期序号，保留非日期测量值。

原文件仍由使用者在界面关联，不硬编码路径。未关联不可写入，预览不修改文件，确认前检查原文件指纹，写前保留备份，锁冲突可在历史重试。升级保留 grid.9 程序和发布包；新程序存入独立 grid.10 版本目录。默认端口 18810，已有配置沿用。

已被旧版修改并丢失格式的文件不会自动恢复。先另存当前文件，再从写入前备份核对格式和业务记录；不要直接以旧备份覆盖新记录。升级后重新生成预览。真实业务文件、真实安装及真实桌面入口均不在自动测试中修改。

写入前原表备份位于使用者配置的数据目录 `backups`，文件名形如 `source-月份-项目-*.xlsx`。恢复时先保留当前文件，再核对和另存备份，避免覆盖随后新增的记录。

旧版未确认候选禁止直接提交，须重新生成预览。旧版中断写入只有原文件和月份副本均已保存相同候选时可完成收据；否则保留现场与备份，拒绝继续覆盖文件，需人工核对。

验收使用隔离副本，覆盖 XML 限定属性、冻结窗格、固定列宽、原有历史值和样式、空单元格完整属性、新增行样式及行高、范围不缩小、合并/打印/链接保留，并复跑关联写入、月模板、格式设置、浏览器和中文安装。具体通过项与版本见发布目录 JSON；Excel/WPS 原生打开及真实手机仍须现场核对。
