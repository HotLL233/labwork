## 仍需现场验收

- 未在实验室实际 Excel/WPS 中执行完整“打开、重算、保存、再回写”验收。自动验证可证明无关文件部件被保留，不能证明所有办公软件版本的绘图、打印和公式行为。
- 实验室方法依据、浓度、空白值、舍入规则与模板语义尚未由业务人员核定。试用样表不作为正式检测结果；真实副本提交前要求管理员确认。
- Windows 正式服务注册、LocalService 权限、防火墙及客户端证书分发需要在实际服务主机安装后验收。本次仅验证隔离提取负载与同一服务启动器，没有安装生产系统服务。
- 浏览器 UI 工具在当前会话没有可用浏览器，页面通过 Django 服务器渲染和 HTTP 检查，未完成浏览器截图视觉验收。
- 首版尚未实现其他 10 项目全方法、历史结构化导入、通用批量录入、设备采集和正式 PDF 签章。

## 可复现命令与证据

自动检查：`APP_ENV=test python manage.py test records.tests`。

HTTP 检查：`python packaging/smoke_http.py --base <隔离HTTPS地址> --ca <测试根证书> --credentials <随机测试账号JSON> --report <输出JSON>`。它用标准库验证证书、CSRF、登录、并发重复提交、全部试点方法、任务状态与下载。只对明确的隔离部署执行。

运行报告保存于开发工作区被排除的 `runtime/windows-smoke/http-report.json`、`runtime/docker-verify/http-report.json`、`runtime/restore-smoke/report.json`。正式业务文件不纳入源码；发布目录提供二进制包及校验和。
